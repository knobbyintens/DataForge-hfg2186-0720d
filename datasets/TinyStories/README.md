# TinyStories

Processed instruction dataset released by Helio Data Labs.

This dataset is derived from our raw corpus TinyStories-Raw. The instruction/response pairs were synthesized from that raw corpus with [Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct). The underlying original corpus is [roneneldan/TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories).

- Source dataset: TinyStories-Raw
- Synthesis model: Qwen/Qwen2.5-7B-Instruct
- Original corpus: roneneldan/TinyStories
- Records: 1,180,000 instruction/response pairs
- Format: JSONL with fields `instruction`, `response` and `source_story_id`
